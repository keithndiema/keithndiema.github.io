Quantitative Infrastructures & Algorithmic Frameworks

Vestora [Python, Quantitative Engineering]

An analytics engine engineered to process financial data and forecast market shifts, explicitly optimized for emerging market indicators like the Nairobi Securities Exchange (NSE). Built using customized walk-forward backtesting pipelines to restrict parameter optimization within historic boundaries and mitigate data leakage.

Optimization engine objective function targeting financial structural variables ($\theta$): $$J(\theta) = \sum_{t=1}^{T} \left( y_{t} - f(x_{t}; \theta) \right)^2 + \lambda \Vert{}\theta\Vert{}_2^2$$
Traffic Sentinel [Python, Spatio-Temporal ML]

A data-driven traffic intelligence platform engineered to identify high-risk time windows and predict accident hotspots. Deploys spatial-temporal computing layers to turn raw historical regional incident records into active, actionable analytical safety insights.

AgriGuard [ML, Price Forecasting, Cross-Platform UI]

Agricultural intelligence software modeling commodity price volatility using a blended time-series ensemble of XGBoost and additive forecasting architectures (Prophet). Designed with a multi-channel architecture serving responsive API payloads alongside compressed network frameworks down to low-bandwidth USSD platforms, maintaining systemic reliability for rural smallholder farmers.

Additive components breaking down trend ($g$), seasonality ($s$), and holiday indicators ($h$): $$y(t) = g(t) + s(t) + h(t) + \epsilon_t$$
